# Suzuki PDF Viewer

Windows 用の PDF ビューアー・エディター「Suzuki PDF Viewer」の配布場所です（ソースコードはありません）。

- **はじめて入れる**：[最新のリリース](https://github.com/phkdow/suzukipdf-updates/releases/latest) から `SuzukiPDF-Setup-x.y.z.exe` をダウンロードして実行します。
  「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押してください。
- **更新**：アプリが起動時に自動で新しいバージョンを確認します（「ヘルプ」→「更新を確認」でも確認できます）。
  手動で更新するときは、`SuzukiPDF-x.y.z.suzukipdf-update` をダウンロードしてダブルクリックします。
- 更新ファイルには電子署名が入っていて、正式なもの以外はアプリが受け付けません。
